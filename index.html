PERTANYAAN UMUM

Frequently Asked Questions

Hal-hal yang sering ditanyakan seputar kerja sama, proyek web, dan keahlian teknis saya.

Ya, tentu saja! Sebagai siswa RPL di SMK Telkom Lampung, saya sangat terbuka untuk program Praktik Kerja Lapangan (PKL), magang industri, maupun kerja sama pembuatan website secara freelance.

Untuk tampilan antarmuka (Front-End), saya menguasai HTML5, CSS3 murni, Tailwind CSS, Bootstrap, dan JavaScript modern (ES6+). Untuk Back-End dan basis data, saya menggunakan PHP, Laravel, serta MySQL.

Tergantung skala dan kompleksitas proyek. Untuk Landing Page atau Web Portofolio sederhana biasanya memakan waktu 3-7 hari kerja. Untuk sistem informasi berbasis data (CRUD), membutuhkan waktu 1-3 minggu.

Anda dapat langsung menghubungi saya melalui tombol WhatsApp di bawah atau mengisi formulir kontak. Kita akan mendiskusikan kebutuhan, brief desain, estimasi waktu, dan mock-up awal secara fleksibel.
